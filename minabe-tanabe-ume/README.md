# Minabe–Tanabe Ume System

Live: https://sophiachen-geo.github.io/no-one-is-an-island/minabe-tanabe-ume/

Where the FAO GIAHS "Minabe–Tanabe Ume System" is: its official area, the ume orchards and ubame-oak coppice,
and 20 sites that run it, on 2025 satellite imagery with aerial close-ups. Static, self-contained `index.html`;
deploy.yml copies this folder into the site as-is.

| Layer | Source | Vintage |
|---|---|---|
| Upland fields 畑 (mostly ume orchards) | MAFF field polygons 筆ポリゴン, land type 畑 | 2026 release (parcels edited 2020–2025) |
| Ubame-oak coppice ウバメガシ二次林 | MoE Biodiversity Center, Current Vegetation Map 2024 | surveys 2001–2003 (newest species-level mapping) |
| GIAHS area (Minabe + pre-2005 Tanabe City) | MLIT 国土数値情報 N03, after the GIAHS application map | 2025 and 2000 boundaries |
| Sites | GIAHS council resource map and application, OpenStreetMap, Wikidata | 2026 |
| Base imagery | Sentinel-2 cloudless 2025, EOX (CC BY-NC-SA 4.0) | 2025 |
| Close-ups | GSI seamless aerial photos 出典：国土地理院 | latest GSI orthophotos |

Areas inside the GIAHS area: upland fields 2,309 ha (Minabe) and 2,982 ha (Tanabe part); ubame-oak coppice 202 ha (Minabe) and 1,054 ha (Tanabe part).
Upland fields also include some citrus and vegetables; the vegetation map undercounts coppice mapped as other broadleaf forest.
