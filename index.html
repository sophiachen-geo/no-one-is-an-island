點一座島嶼，文字會浮現。

大家好，我是 Sophia Chen。

我在福州出生，家裡有人來自馬祖。小時候，我的父母先移民到非洲的多哥共和國，後來又到了加拿大魁北克。我曾經在瑞士讀建築、工作，也回到那裡交換學建築。除此之外，我也在台北、加拿大北極地區、中美洲、巴貝多，以及其他地方生活和工作過。

所以如果要很簡單地介紹我自己，我會說：我是一個一直在邊界之間長大、移動和思考的人。

我的母語是閩東話，父語是法文。我從小就體會到，語言不只是溝通工具，語言本身也是一種邊界。你能說什麼語言，常常會影響你能不能被理解、被聽見、被承認，甚至能不能在某個地方找到自己的位置。

我也成長在很多不同的信仰與文化環境裡：佛教、道教、儒家思想、天主教、基督教、伊斯蘭教，也包括東正教。七年前，我曾經去保加利亞一個禮拜，研究和學習東正教文化。所以這次來到希臘，我也很自然地會注意到宗教如何影響空間、城市、島嶼和人的日常生活。

但對我來說，這些經驗不只是「我去過很多地方」。它們讓我很早就意識到：世界不是由乾淨、固定、絕對的分類組成的。

大陸與台灣，法語的魁北克與英語為主的加拿大，原住民與非原住民，少數民族與漢族，正式與非正式（formal / informal），公共與非公共（public / non-public），可見與不可見（visible / invisible），中心與邊陲（center / periphery）——這些分類都是真實的，因為它們會影響身份、權力、資源和生活。但它們也從來不是自然、固定、無辜的。

所以我最感興趣的第一件事，是邊界。

不是因為我相信邊界是絕對的，而是因為我想知道：邊界是誰畫的？誰被放進去？誰被放在外面？誰被看見？誰又被消失？

這對我來說也是一個認識論上的挑戰（epistemic challenge）：我們到底用什麼方式看世界？誰的知識被承認？誰的經驗被忽略？誰的語言被認為是正式的？誰的空間被認為是公共的？

所以跨領域（interdisciplinary）對我來說不是一個漂亮的學術標籤。它是我理解世界的方式。因為世界本來就不是被清楚切開的。

我研究島嶼快十年了。

對我來說，島嶼不只是地理上的研究對象。它也是一種思考世界的方法。

島嶼看起來像邊界很清楚的地方：被海包圍，好像和其他地方分開。但事實上，島嶼從來不是封閉的。島嶼連接海洋、港口、船、風、等待、離開、回來、遷徙、戰爭、貿易、災害、記憶和想像。

我曾經去過三十幾個國家，橫跨四大洲，但我一直記得一個畫面：那一夜在加拿大北極的無人島上，枕著冰層入睡，聽見冰川掉落前的聲音。那時候我很強烈地感覺到，極端的邊界不是世界的例外，而是世界發聲的裂口。很多時候，不是地球無語，而是我們太久沒有傾身去聽。

而島，對我來說，是極端之中最溫柔的試煉。

它是地形，是語境，也是韌性的縮影。在無法選擇的地理中，練習重塑生存的秩序；在資源斷裂之處，建立屬於自己的敘事與結構。

我很喜歡一句話：「沒有人是一座孤島」（No one is an island）。

但我也想反過來說：沒有任何一座島真的只是一座島。

對台灣學生來說，我覺得這件事情尤其重要。因為台灣本身就是一座島，而且在很多歷史敘事裡，台灣常常被放在中心—邊陲（center-periphery）的關係裡理解。

在歷史課本裡，台灣常常像是不同王朝、帝國、殖民系統、政權或世界秩序的邊陲。它常常是被觀看、被命名、被治理、被爭奪的地方。

但我覺得我們可以重新想這件事。

邊陲不一定只是離中心很遠的地方。邊陲也不一定只是缺乏資源、缺乏聲音、等待中心承認的地方。邊陲也可以是一個看得更清楚的地方：看見流動、看見關係、看見權力、看見脆弱，也看見韌性。

從馬祖的角度來看，這件事對我更清楚。台灣是一座島，而馬祖是島嶼中的島嶼（an island of an island）。它是邊陲中的邊陲，但也正因為如此，它不是沒有中心，而是可以從自己的位置長出自己的中心。

這也和我們這次要去的地方有關。敘羅斯（Syros）可以被理解為雅典網絡中的一座島：它不一定在行政上屬於雅典，但它和雅典之間有交通、資源、文化、觀光、教育和想像上的連結。而蒂迪米（Didimi）又可以被理解為敘羅斯的島嶼，是島嶼裡更小、更邊緣、更容易被忽略的存在。

所以如果用一種比較性的想像來說，蒂迪米（Didimi）不一定真的等於馬祖，但它可以像「希臘的馬祖列島」一樣，幫助我們思考什麼是島中之島，什麼是邊陲中的邊陲，以及一個看似很小、很邊緣的地方，如何從自己的位置長出中心。

這其實也和我以前在聯合國與國際勞工組織（UN / ILO）做的工作有關。我做過很多和永續發展、青年、經濟未來、勞工權益有關的工作。在那些議題裡，也有非常清楚的中心—邊陲關係：老闆與僱員，資本與勞動，政策制定者與被政策影響的人，全球中心與地方社群。

所以中心和邊陲不只存在於地理裡。它也存在於經濟裡，存在於勞動關係裡，存在於知識生產裡，也存在於我們每天如何理解自己和他人的方式裡。

因此，我不太想用「我們要讓別人知道我們很重要」這種方式來理解島嶼。

我更想問的是：我們的力量從哪裡來？我們如何從自己的位置、自己的歷史、自己的生活經驗出發，重新理解世界？

這是一種由內而外的力量（from within outward）。

沒有人該是一座孤島。 但若命定身在島上，便學會成為他人的岸。 每一道邊緣，終將長出自己的中心。

我現在在加拿大紅十字會擔任社群製圖負責人（Community Mapping Lead）。我之前也在加拿大聯邦政府工作過。關於我的工作，下週我會有比較完整的時間跟大家分享。

如果要說我關心什麼，我常常會說：我關心的是環境、政策、數據和人之間的交界。

這裡的環境，不只是自然環境，也包括地理環境、人文環境、社會環境和政治環境。

我自己有很強的技術和理工背景。我做地理資訊系統（GIS）、空間分析、資料處理、災害風險和社群製圖。但同時，我也出過詩集，從小學音樂。我的父母雖然後來回到家族的法律與教育領域，但他們原本都是藝術畢業的。所以我從小也受到藝術、文學、音樂和語言的影響。

我最著迷的東西，其實一直是符號系統（symbolic systems）。

  • 語言是一種符號系統。
  • 數學是一種符號系統。
  • 地圖是一種符號系統。
  • 建築是一種符號系統。
  • 宗教、音樂、法律、城市，也都是人類理解世界、組織世界、想像世界的方法。

所以對我來說，製圖（mapping）從來不只是把資料放到地圖上，也不只是做一張好看的圖。製圖是一種符號系統（symbolic system），也是一種再現（representation），而這兩件事放在一起，就是我所理解的意義生成（meaning-making）。

也就是說，製圖不是意義生成之外的一個工具。製圖本身就是意義生成的一部分。

地圖用線條、顏色、尺度、分類、圖例、邊界和空白來組織世界。它看起來好像很中立，但地圖從來不是完全中立的。它會選擇什麼被看見，也會決定什麼被忽略。

所以我關心的不只是：我們要畫什麼？

我更關心的是：我們為什麼要畫？我們從誰的視角出發？誰被放在中心？誰被放在邊陲？什麼被看見？什麼又被消失？

這就是我很在意的意義生成（meaning-making）。

意義生成不是把一個漂亮的概念套到作品上。它是你真正知道自己為什麼使用某一種媒介，為什麼選擇某一種符號，為什麼用這種方式再現一個地方、一個人、一段記憶或一種關係。

所以不管你們最後用的是繪圖（drawing）、影像或電影（film）、裝置（installation）、敘事地圖（story map）、感官地圖（sensory map）、記憶地圖（memory map）、行走地圖（walking map），或者傳統地圖，媒介本身都不是重點。

真正重要的是：你想讓什麼被看見？你想讓誰被聽見？你想讓什麼關係被重新理解？你想從哪裡重新建立自己的中心？

我常常說，地理本身就是關係性的（relational）。

但關係性不代表所有東西都可以隨便連在一起。真正重要的是，我們要有意識地問：這些關係是怎麼被建立的？對誰有意義？它們讓什麼變得更清楚？它們又可能遮蔽了什麼？

這也是為什麼我對很多二元對立（dichotomy）都很感興趣：正式與非正式（formal / informal）、公共與非公共（public / non-public）、可見與不可見（visible / invisible）、中心與邊陲（center / periphery）。

我不是說這些差異不存在。相反，它們很重要，因為權力常常就是透過這些分類在運作。但我希望我們不要太快接受這些分類，也不要太快相信世界真的可以被切成兩邊。很多真正有意思的事情，其實都發生在中間、邊界、轉換、模糊和不穩定的地方。

我可以給一個例子。

如果有一個人對自己的身體、外型，或者自己如何被別人觀看感到不安。這不一定是她需要公開分享的事情，也不是我們要把個人的脆弱拿來展示。但如果對她來說，這個恐懼是真實的、有重量的、有意義的，那它就可以成為一個製圖的入口。

如果我們研究的是島嶼、海洋和海盜，那這裡其實有很多可以連接的地方。海盜在我們的想像裡，常常不是一個完整、乾淨、完美的身體。他可能獨眼、斷腿、有疤痕、有義肢。這些身體不是主流秩序裡被認為「完整」的身體，但它們仍然有力量，仍然能行動，仍然能重新命名自己的位置。

這裡就可以連到一個概念：身體作為疆域（the body as territory）。

如果身體是一座島，那它的海岸線在哪裡？它的傷痕在哪裡？它的港口在哪裡？它的風暴在哪裡？它的避難所在哪裡？哪些地方需要保護？哪些地方願意和世界連接？

這樣的製圖可能不是傳統地圖，而是一張身體—島嶼地圖（body-island map）。但在這個過程裡，那個人也許不只是完成一個作品，也可能重新看待自己和自己身體的關係。

這個例子對我來說很重要，因為它同時說明了我最關心的幾件事。

  • 第一，它說明了邊界。身體有邊界，島嶼有邊界，地圖也會畫出邊界。
  • 第二，它說明了再現與意義生成（representation / meaning-making）。同一個身體，可以被外界用一種方式觀看，也可以被自己用另一種方式重新命名。
  • 第三，它說明了轉變（transition）。一個人可以透過製圖的過程，從被觀看、被評價、被規訓的位置，慢慢轉向重新理解自己、重新保護自己、重新與世界連接的位置。

所以對我來說，轉變不是抽象概念。

  • 經濟轉型是一種轉變。
  • 建築裡的再利用（reuse）和重新賦予用途（repurpose）是一種轉變。
  • 災害之後的復原（recovery）也是一種轉變。
  • 一個人重新理解自己的身體、身份和位置，也是一種轉變。

我現在在紅十字會做的工作，很多時候其實就是幫助社區在災害後重新理解自己、重新組織資源、重新建立連結。

復原不只是把東西修回原本的樣子。復原也是一個社區重新問自己：我們失去了什麼？我們還擁有什麼？我們想保護什麼？我們要往哪裡去？

很多時候，真正的改變不是突然發生的。它是在邊界上、在過渡中、在一個人或一個地方還沒有完全知道自己會變成什麼的時候，慢慢長出來的。

這也是為什麼我很支持實驗性的工作（experimental work）。但實驗不能只是形式上的新奇。它不能只是看起來很酷，也不能只是概念聽起來很漂亮。

實驗需要意義（experimentation needs meaning）。

形式可以自由，但邏輯不能是空的。媒介可以很多元，但背後必須有清楚的意圖。

最後，我想說，我希望我們的製圖組不只是做地圖，而是學會講故事，也學會聽故事。

製圖是講故事（mapping is storytelling）。但在講故事之前，我們要先學會聽故事。聽地方的故事，聽人的故事，聽空間裡沒有被說出來的故事，聽那些很小、很日常、很容易被忽略的東西。

這也是為什麼田野調查（fieldwork）對我來說非常重要。田野調查不是為了證明我們原本就相信的東西。田野調查是一種現實檢驗（reality testing）。

很多理論在紙上很漂亮，很多概念在簡報裡很聰明，很多圖像在牆上很好看。但現場會告訴我們：事情沒有那麼簡單。人的路徑、人的等待、人的恐懼、人的沉默、人的生活方式，常常會挑戰我們原本的想法。

所以做地理、做製圖、做田野，很重要的一點是保持謙卑。不要太快相信一刀切的答案，不要太快用同一套方法解釋所有地方，也不要太快把別人的生活變成我們自己的概念材料。

我最喜歡的學習方式，其實是蘇格拉底式對話（Socratic dialogue）。它對我來說也是一種關係性的實踐。好的教學不是我給大家一個標準答案，而是我們一起問問題，一起把看似理所當然的東西拆開。

我們可以一起問：

  • 我們為什麼這樣看？
  • 這個分類從哪裡來？
  • 這張地圖讓誰被看見？
  • 又讓誰被消失？
  • 如果從邊陲看，而不是從中心看，這個地方會變成什麼樣子？
  • 如果從身體看，從記憶看，從災害後的復原看，又會變成什麼樣子？

我其實很好相處。我不需要大家一開始就很會做圖，也不需要大家一開始就有很成熟的概念。我在乎兩件事。

第一個是在場（presence）。簡單講，就是你有沒有到。請大家盡量不要遲到。如果有事，一定要講。沒有什麼事是不能講的。真正麻煩的不是有問題，而是不說。

第二個是在場的品質（quality of presence）。你人在這裡的時候，你是不是真的在？你有沒有看？有沒有聽？有沒有想？有沒有對別人的故事、地方的細節、自己的作品負責？

我相信，如果一個人一直認真地存在，她不可能做出完全不好的作品。因為真正的作品不是突然變出來的，它是從注意力、誠實、觀察和投入裡長出來的。

我知道你們這一代面對的挑戰很多。氣候危機、戰爭、經濟不穩定、孤獨感、未來的不確定性，這些都不是小事情。我之前在聯合國與國際勞工組織（UN / ILO）做青年代表時，也一直在處理年輕人、工作、未來和政策之間的問題。

所以我做製圖、研究島嶼、談「沒有人是一座孤島」（No one is an island），對我來說不只是學術興趣。它也有一個很簡單的人道主義願望。

我希望有一天，當你們遇到困難，或者只是覺得迷失、不確定、不知道自己在哪裡的時候，你們看到一座島，不只會想到孤立，也能想到連結、中心、想像和勇氣。

  • 看到一座島，也許可以想到：即使被海包圍，也還是可以和世界相連。
  • 看到一座島，也許可以想到：即使被稱為邊陲，也不代表沒有力量。
  • 看到一座島，也許可以想到：中心不一定要被別人給予，有時候中心是我們從自己的位置慢慢長出來的。
每個人都像一座小島，有自己的邊界、記憶、傷痕和風暴。 但同時，沒有人真的應該是一座孤島。

而那座正在長出自己中心的島，也可能就是正在瘋狂成長的你。

所以我希望我們的製圖組可以是一個這樣的空間：我們不只是畫地圖，而是用製圖去觀察、去聆聽、去連結、去測試現實，也去創造意義。

因為沒有人是一座孤島。 而每一座島，也都不只是島。

謝謝你們。
